# ShengWen 总结（讲稿转熟文本笔记）

## Overview

将口语化的转录文本/讲稿整理为结构清晰、逻辑连贯、易于阅读的 Markdown"熟文本"总结。核心方法是 ShengWen 项目沉淀的"整理四步"：预处理翻译 → 整理总结 → 结构化处理 → 增强展示。

## Workflow

### Step 1: 确认输入

- 用户提供了**字幕/文稿文件路径**（.srt/.vtt/.ass/.ssa/.txt/.md）→ 使用脚本解析。
- 用户直接**粘贴了文本**（转录稿、讲稿、会议记录等）→ 直接使用。
- 用户只给了**视频/音频 URL 或文件名**但无字幕 → 说明本 skill 只处理文本，请先获取字幕或转录稿；如需全流程可提示使用 ShengWen 项目本体。

### Step 2: 解析文件（如有）

对字幕/文稿文件，用脚本将其解析为纯转录文本：

```bash
python scripts/parse_subtitle.py <输入文件> --output <临时文本文件>
```

- 输出格式：每行以 6 位时间戳（HHMMSS）开头，如 `001512hello world`；纯文本原样保留。
- 解析后读取文本内容作为输入；若脚本报错，检查编码（建议 UTF-8）后重试。

### Step 3: 加载总结风格

读取 `references/summary-guidelines.md`，严格遵循其中的四步方法论与输出要求。

### Step 4: 执行总结

按文本规模选择策略：

- **短文本（约 4000 字以内）**：一次性总结。
- **长文本（超出上下文或超过约 4000 字）**：采用分块策略——
  1. 按时间戳/语义边界切块（每块约 2000-4000 字）。
  2. 逐块总结：首块生成 `{{主题}}` 标签并建立结构；中间块参照前块末尾与已用标题自然续写、避免重复；末块收尾。
  3. 组装各块，去除分块痕迹（`{{chunk_N_ended}}`、state_ops 等协议标记），统一标题序号，使全文读起来像一次性写成。

### Step 5: 输出

- 直接输出 Markdown 总结文档（默认）。
- 如用户指定或更合适，将结果写入 `.md` 文件（建议与输入同名，如 `xxx_总结.md`）。
- 输出必须满足：`{{主题}}` 开头、标题带序号、`[小结]` 提炼观点、时间戳标注、适当 Mermaid 图表、无任何处理过程说明。

## 关键准则（摘要）

- 保留 >70% 原文表述，禁止过度删减；细节、例子、数字必须完整。
- 修正语音识别错别字（尤其同音字）；非中文翻译为简体中文。
- 标题全部带序号；emoji 仅用于一级标题。
- 时间戳每 300-500 字标注一次，关键转折必标，格式 `(见 00:00:10)`。
- 主题标签要有洞察性，不要平淡（如 `{{市场报告}}`、`{{作者心声}}`）。
