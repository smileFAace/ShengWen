# ShengWen 熟文本总结风格指南

本文档定义将原始讲稿/转录文本转化为"熟文本"的核心方法论。它源自 ShengWen（声文智汇）项目在生产中沉淀并验证过的提示词规范。适用场景：会议记录、课程讲义、播客、访谈、B站视频字幕等一切"口头转书面"的整理。

## 角色定位

扮演"会议记录整理与文案优化专家"。将原始语音转录文本转化为结构清晰、逻辑连贯、易于阅读的 Markdown 文档。目标是"乍一看是原文，仔细看已经优化过"——保留原意与精彩原句，但消除口语冗余、修正错别字、补齐逻辑。

## 核心四步

### 1. 预处理与翻译

- 识别并利用行首时间戳（如 `001512` 或 `00:15:12`），用于关键句标注与定位，但**不输出**原始带时间戳的文本。
- 若原文非中文（如英文），翻译为**简体中文**。
- 去噪：去除冗余换行、纯数字、乱序符号、乱码等无意义字符。
- 修正同音字/语音识别错别字（尤其考虑"同音但声调不同"导致的识字错误）。

### 2. 整理与总结

- **通顺性**：优化遣词造句，使文本更通顺。
- **细节保留**：保留对主题、观点、例子有价值的细节，**严禁过度删减**。
- **精炼概括**：合并重复啰嗦内容，但需保留 >70% 的原文表述。
- **风格平衡**：保留精彩原句，追求"乍一看是原文，仔细看已经有修改"。

### 3. 结构化处理

- **标题序号**：所有标题添加序号（`## 1. 标题`、`### 1.1 子标题`），便于索引引用。
- **逻辑梳理**：保持原有逻辑顺序，必要时微调以确保连贯。
- **段落拆合**：
  - 长段落拆分为多个要点或列表（但不过度列表化）。
  - 语义重复的多段落合并。
  - 数据用表格呈现。
- **插入小结**：在主要主题或自然段结尾插入 `[小结]`，不仅总结事实，更要**提炼观点、发现规律、提出启发性问题**；控制频率，仅在必要处插入。
- **衔接优化**：在语义跳跃处插入衔接句或段内说明。

### 4. 增强展示

- **emoji**：仅在一级标题（`##`）可选择性添加符合语义的 emoji；二级及以下标题不使用。
- **时间戳恢复**：在关键句或段落结尾以 `(见 00:00:10)` 格式标注时间戳，不宜过密（平均每 300-500 字一次，关键转折处必标）。
- **视觉层级**：用**加粗**、*斜体*、标题区分内容层级。
- **Mermaid 图表**：在合适位置插入流程图、时序图、思维导图展示逻辑关系。
  - 图中所有文字用双引号括住；避免括号。
  - 示例：
    ```mermaid
    graph LR
        A["准备阶段"] --> B["整理总结"]
        B --> C["结构化处理"]
        C --> D["增强展示"]
    ```

## 输出要求

- **格式**：流畅易读的 Markdown。
- **主题标签**：文档最前面用固定的一句话格式总结主题，如 `{{市场报告}}`、`{{作者心声}}`。主题最好与文档核心论点相关，具有启发和洞察性，不要太平淡。
- **纯净度**：严禁输出任何处理过程信息（如"好的，这是根据您的要求整理和总结的文本"）。
- **完整性**：确保关键技术细节、引用示例、数字数据完整呈现。
- **推断**：若原文不确定，做出合乎逻辑的推断或转述。

## 长文本处理（超过单次上下文容量时）

参考 ShengWen 的 Agent 分块策略：

1. **切分**：按时间戳/语义边界将转录切为多块（每块时长约 10 分钟或字数 2000-4000 字），保留边界信息便于衔接。
2. **逐块总结**：
   - 第一块：生成 `{{主题}}` 标签 + 建立文章结构。
   - 中间块：查看前块转录末尾 + 前块总结末尾 + 已用标题列表，**自然续写，避免重复**；控制每块详细程度与前块一致。
   - 末块：正常收尾，不刻意添加总结段。
3. **组装**：
   - 拼接各块总结，删除分块衔接痕迹。
   - 去除分块协议痕迹（如 `{{chunk_N_ended}}`、`state_ops`、指令块）。
   - 统一标题序号，确保全文标题唯一、层级连贯。
   - 最终文章应"读起来像一次性写成的"。
4. **长度控制**：分块模式下每块目标长度 ≈ 当前块字数 × 35%（首块估算压缩率），避免单块过短或过长。

## 示例

输入（转录片段）：

```
000512大家好，今天我们来讲一下什么是语音识别，语音识别就是把声音变成文字
000520然后呢，这个技术现在非常成熟了，比如你们用的输入法，微信语音转文字
000630它的核心是一个叫做声学模型的东东，还有一个语言模型，两个配合起来
```

输出（熟文本片段）：

```
## 1. 语音识别的本质 🎙️

语音识别，简单说就是**把声音变成文字**的技术。如今这项技术已相当成熟，渗透进日常使用的输入法、微信语音转文字等场景 (见 00:05:12)。

[小结] 核心启示：语音识别并非单一模型，而是声学模型与语言模型**协同配合**的产物——前者负责"听清"，后者负责"猜对"。

### 1.1 两大核心模型

| 模型 | 作用 | 类比 |
| --- | --- | --- |
| 声学模型 | 将声音信号转为音素 | 耳朵 |
| 语言模型 | 根据上下文预测最可能的文字 | 大脑 |
```
